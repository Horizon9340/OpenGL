# OpenGL

### *** Repo in progress ***

This is a much more optimized OpenGL program, and I currently am learning 3D and matrices (linear algebra).

## Finished Product

I made a basic 3D model with a camera, along with keyboard inputs. The code is better structured, better organized, and more coherent than my first few OpenGL projects.

The program currently renders a rectangular prism. By using `W, A, S, D` you can move the camera around on the x-z plane, and `UP ARROW, DOWN ARROW` to move the camera along the y-axis. My next step is going to be mouse inputs to modify the orientation vector of the camera (the angle with which it looks at things).
